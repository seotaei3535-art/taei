# 취향의 서가

좋아하는 영화와 음악을 소개하는 반응형 홈페이지입니다.

## 실행

`index.html`을 더블 클릭하면 브라우저에서 열립니다. 별도 설치가 필요 없습니다.

## 파일

- `index.html`: 제목, 영화 및 음악 소개글
- `style.css`: 색상, 배경, 모바일 화면 구성
- `script.js`: 음악 장르 선택 버튼
- `images/library.png`: 제공한 서점 배경 이미지
- `favicon.svg`: 브라우저 탭 아이콘

## GitHub에 올리기

1. GitHub에서 새 저장소를 만듭니다.
2. **Add file → Upload files**에서 이 폴더 안의 모든 파일과 `images` 폴더를 올립니다. `index.html`이 저장소 최상위에 위치하도록 올려주세요.
3. **Commit changes**를 누릅니다.
4. 홈페이지를 공개하려면 **Settings → Pages → Deploy from a branch**에서 `main`과 `/(root)`를 선택하고 저장합니다.

배경 이미지에는 원본의 기관 표기가 포함되어 있습니다. 공개 게시 전 이미지의 사용 권한을 확인하거나 사용 가능한 사진으로 교체하세요.

사이트의 소개글은 전달한 장르 취향을 바탕으로 작성한 초안입니다. 실제 좋아하는 영화명이나 곡명을 넣으려면 `index.html`을 수정하면 됩니다.
